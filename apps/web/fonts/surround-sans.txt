# Surround Sans: the pixel face for Surround's display type.
#
# Each glyph is a "== <character>" line (or "== U+XXXX") followed by its
# bitmap: 8 rows from the cap line down to the baseline, then optionally 2
# descender rows. "#" is ink and "." is empty. The rows' width is the glyph's
# width; every glyph advances by its width plus one cell.
#
# Cap height and ascenders are 8 cells, the x-height 6. Round corners lose
# their corner cell. Digits are all 6 cells wide so numbers line up.
#
# Rebuild the fonts after editing: uv run scripts/build-surround-sans.py
