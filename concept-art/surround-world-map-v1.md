# Surround world map — concept v1

Generated with the imagegen skill using the built-in image-generation tool. This is an image-first UI concept; it has not been implemented in the web app.

Image: `surround-world-map-v1.png`

## Direction

Region selection becomes an explorable world of Go rather than a technical server menu. Anonymous activity lights show where communities are active, pavilion markers act as regional destinations, and the selected-region card provides player count, open tables, connection quality, and a direct path into that region's lobby.

The map intentionally displays aggregate regional activity rather than exact player locations.

Style/medium: premium 16-bit / 32-bit pixel-art game interface with deliberate clusters, controlled dithering, elegant cartography, cream pixel-display headings, and restrained luminous gold accents.
Composition/framing: wide 16:9 desktop screenshot. The map occupies roughly 70% of the frame, with a narrow region rail and a floating selected-region card that does not obscure the geography.
Lighting/mood: midnight-blue global calm with pools of lantern warmth; inviting, contemplative, and connected across distance—the feeling of choosing which distant Go club to visit tonight.
Constraints: aggregate activity only; no exact addresses, national flags, emphasized political borders, country ranking, photorealism, smooth 3D globe, sci-fi hologram, cyberpunk neon, mobile layout, chess pieces, or watermark.
